# Техническое задание: KMHTO — учёт и планирование ТО/КМХ

## 1. Назначение

Приложение для учёта, планирования и контроля метрологического обслуживания
оборудования (ТО и КМХ), работающее с данными из Excel-файла графика.

## 2. Источник данных

Файл: `TOKMHver5.xlsx` (образец). Структура листов:

| Лист | Назначение | Структура |
|---|---|---|
| `1` | График ТО (журнал) | столбцы: № п/п, Код СИ/оборуд., Наименование, Место установки, январь…декабрь; в ячейках месяцев — виды ТО (`ТО-1 (день)`, `ТО-3 (день)`) |
| `3` | График КМХ / дат | те же столбцы; в ячейках месяцев — дни (числа), возможно несколько в одной ячейке |
| `data` | Справочник оборудования | код, наименование, работы при ТО-1/ТО-2/ТО-3, нормы, ссылка на техкарту |

### 2.1. Семантика

- колонка = месяц (январь…декабрь), месяц определяется по колонке;
- ячейка = список дней месяца (пользователь вводит вручную, возможны ошибки);
- строка = вид работ (ТО-1 / ТО-2 / ТО-3 / КМХ);
- ТО и КМХ — разные графики, участвуют совместно в планировании;
- поле «Объект» = значение колонки «Место установки» дословно.

### 2.2. Грязные данные (обязательно обрабатывать)

- переносы строк внутри ячейки (`14,\n20,\n2`);
- смешанные разделители (запятая, точка с запятой, слэш, перенос);
- лишние и хвостовые разделители (`14,20,2,`);
- лишние пробелы, мягкие переносы, похожие кириллические и латинские символы;
- объединённые ячейки (merged) и разрывы в строках;
- недопустимые значения: день `> 31` или `0`.

## 3. Функционал

### 3.1. Импорт и авто-парсинг

- открытие файла → автоматический разбор без отдельных кнопок;
- настройка через панель: лист, строка заголовка, строка начала данных;
- определение колонок по именам (устойчиво к вставке столбцов) либо по буквам;
- учёт объединённых ячеек и разрывов;
- единый конфиг (localStorage / `settings.json`) — все настройки в одном месте;
- один импорт, один экспорт — минимум разрозненных файлов.

### 3.2. Планирование

- планирование на годы вперёд с интервалом в днях;
- допуск ± дней вокруг интервальной даты (окно проведения);
- выходные (Сб/Вс) подсвечиваются красным, есть отдельный ввод дополнительных
  выходных (переносы, праздники);
- сдвиг даты с выходного на ближайший рабочий;
- ТО-3 выделяется жирным на календаре;
- правила планирования и автогенерация графика на выбранный год с продолжением
  от последней даты прошлого года.

### 3.3. Календарь года

- отдельная вкладка: весь год по месяцам;
- клик и ПКМ по дню → контекстное меню действий;
- навигация по годам;
- метки поверки и калибровки.

### 3.4. Перестановки и переносы

- перестановка ТО-3 ↔ ТО-1/ТО-2 соседнего месяца;
- у переноса и перестановки — обязательный комментарий причины;
- история переносов, стрелки «откуда → куда».

### 3.5. Учёт за год

- суммарное количество ТО-1 / ТО-2 / ТО-3 / КМХ за год;
- сверка с интервальными датами и с технологическими картами (нормами).

### 3.6. КМХ (поверка/калибровка)

- отдельный ввод данных по поверке и калибровке;
- вывод КМХ в одном листе (без лишних вкладок);
- выгрузка всех данных по оборудованию в таблицу.

### 3.7. Динамические колонки

- возможность добавлять столбцы (в `data`) и включать их в алгоритм;
- типы колонок: текст, число, дата, выбор, чекбокс, ссылка.

### 3.8. Экспорт

- выгрузка по оборудованию;
- формирование заявки на работы (по датам/выделенным);
- экспорт графика в Excel с сохранением структуры исходного файла.

## 4. Интерфейс

- единый экран, минимум вкладок: График / Календарь / Оборудование / Изменения / Сеть;
- планирование через правое меню (ПКМ) с дублированием в меню шапки;
- масштабирование: адаптивная сетка, Ctrl +/−/0;
- авто-парсинг при открытии;
- светлая нейтральная тема (системный шрифт, синий акцент).

## 5. Технические решения

- веб-приложение: HTML + Bootstrap + SheetJS, работа в браузере без сборки;
- сервер совместной работы: Node.js, встроенный `node:sqlite`, собственный WebSocket;
- запасной транспорт — HTTP-опрос (`/api/msg`, `/api/events`) для хостингов, где
  прокси не туннелирует WebSocket;
- автономная работа: без сервера все данные хранятся в браузере.

## 6. Открытые вопросы

1. Семантика строк листа `3` — какая строка = какой вид работ (ТО-1/2/3, КМХ)?
2. Интервалы в днях для каждого вида работ по умолчанию.
3. Год планирования по умолчанию и источник года.
4. Нужны ли динамические колонки в текущем объёме.
